Use this iPhone as a camera

Joins session {{SESSION}}. No app needed. The first time only, iPhone needs this host's security certificate so Safari will allow the camera.

  1. Download the certificate Download SyncCam certificate Tap Allow when asked, then Close.
  2. Install it
    Open Settings → General → VPN & Device Management, tap SyncCam Local CA and Install.
  3. Trust it
    Open Settings → General → About → Certificate Trust Settings and turn on SyncCam Local CA.
  4. Open the camera

Steps 1–3 are needed once per iPhone for this host phone. The certificate only lets this iPhone trust the SyncCam host on your local network; you can remove it any time in the same Settings screen.
